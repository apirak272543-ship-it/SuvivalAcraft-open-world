# กติกาเกม

## การอยู่รอด
- มีค่าความหิว / กระหาย / HP / stamina
- สตาร์ฟเมื่อความหิวหรือกระหายเป็น 0 -> HP ลด
- กินอาหารเพื่อเพิ่มความหิว; หายจากแผลเมื่อความหิวสูงกว่าเกณฑ์

## โลกและบล็อก
- เลิกขุดด้วยมือสำหรับบล็อกที่ต้องเครื่องมือ (stone -> pickaxe, log -> axe)
- บล็อกที่ต้องเครื่องมือระดับ 2+ ต้องมีเครื่องมือระดับนั้น (iron_ore ต้อง pickaxe lvl2)

## คราฟต์
- ใช้โต๊ะคราฟต์ (crafting_table) หรือเตา (furnace) ตามสูตร
- ต้องมีวัตถุดิบครบตามจำนวน; ผลลัพธ์เข้า inventory

## ศัตรูและของรางวัล
- ศัตรูมี hp/armour/damage/xp; อาวุธมี crit
- ฆ่าศัตรูได้ xp และ drop loot ตามตาราง

## ภารกิจและเลเวล
- ภารกิจจบเมื่อเก็บ/คราฟต์/ฆ่าครบจำนวน; ได้ xp + ของรางวัล
- xp เพิ่มเลเวล (เลเวลละ 100 xp)
